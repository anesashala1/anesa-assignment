Final Assignment for Coding for Economists course

To reproduce my Stata project, please download all the files from this repository. Start by opening Stata, then load my .dta file and open the .do files. You can run each part step by step as shown, or simply run the master.do file to execute everything automatically.

To reproduce the analysis, clone this repository and open final_assignment.py in VS Code or any Python environment.
Then run the script from the project root — it will read the raw EPL data, clean it, generate summary tables and a plot, and save all outputs automatically to the outputs/ folder.
